    What is a programming language?

    A formal system for expressing algorithms, data manipulation, rules and interactions with computers. Code follows the language's syntax (how valid code is written) and semantics (what it means). A compiler, interpreter, virtual machine, runtime, or a mix of these then executes or translates it into operations the computer can perform.

    Career lensLanguages are the most visible skill on a CV, but employers hire for the fundamentals a language carries: problem decomposition, debugging discipline, testing and system thinking. Treat a language as a vehicle for fundamentals.

    Compiled to native machine code before it runs.

    C · C++ · Go · Rust

    Bytecode + virtual machine

    Compiled to an intermediate form, executed by a runtime.

    Java → JVM bytecode · C# → .NET IL

    Interpreted / runtime

    Executed by a language runtime; modern ones also use JIT compilation.

    Python · JavaScript

    Transpilation

    One source language transformed into another before execution.

    TypeScript → JavaScript

    Keep in mind: "compiled" and "interpreted" are simplified labels. Modern runtimes combine parsing, bytecode, JIT compilation, caching, optimisation and native execution.

    Deep dive: what happens when you "run" Python or JavaScript Mid

    1. Lexing/parsing: source text is tokenised and parsed into an abstract syntax tree (AST).
    2. Lowering: the AST becomes bytecode (CPython .pyc; V8 Ignition bytecode).
    3. Execution + profiling: the interpreter runs bytecode and records type/branch profiles of hot paths.
    4. JIT optimisation: hot functions are recompiled to machine code (V8 TurboFan, PyPy tracing JIT). Broken assumptions trigger a deopt back to the interpreter.
    5. Runtime services: garbage collection, built-ins and FFI boundaries run alongside your code.

    Consequences: the first run of Python code is slower than the second (bytecode caching); micro-benchmarks can lie (JIT warm-up); a deopt explains why a function suddenly slows down after a type change.

    Deep dive: type systems, the most transferable concept

    AxisMeaningExamples
    • Gradual typing is the industry's compromise: Python typing (mypy/pyright) and TypeScript add static guarantees without losing dynamic flexibility.
    • Generics let code work over many types safely; understanding variance (in/out, covariance/contravariance) is a real mid-level discriminator.
    • Sum types / pattern matching (Rust enum + match, sealed classes in Java/Kotlin, TS discriminated unions) make invalid states unrepresentable.
    • Testing types: in static languages the compiler is a free, fast test suite; dynamic languages need more tests to cover what a compiler would catch.

    SQL & database programming

    SQL (Structured Query Language) is generally considered a programming language, more specifically a domain-specific language (DSL) for querying and managing relational databases. It is declarative: developers describe the desired data operation or result, while the database management system determines how to execute it. SQL complements general-purpose languages such as Python, Java, C#, JavaScript, Go and Rust.

    Declarative vs. imperativeIn Python you write the loop that walks through customers and keeps the German ones. In SQL you write SELECT name FROM customers WHERE country = 'DE', and the database's query planner chooses whether to scan the table or use an index. Most applications use both: a general-purpose language for logic, SQL for the data.

          AI-assisted development

          AI coding assistants are standard: 82% of developers in Stack Overflow's 2025 survey used OpenAI's GPT models for development in the past year. That changes what to learn.

          Fundamentals matter more

          Assistants accelerate people who can review, correct and verify code, and amplify gaps for those who can't.

          Verification is the career

          Describe requirements precisely (inputs, outputs, edge cases, constraints), then test the result like code you didn't write.

          Know what you ship

          You own licence, security and correctness. Never paste secrets into assistants; scan generated dependencies.

          Language synergy

          Help is strongest in mainstream languages (Python, TypeScript, Java) and weaker in niche languages and internal frameworks.

          Still differentiating: problem decomposition, architecture, debugging production systems and judgement about tradeoffs.

                From a QA perspective

                A QA engineer doesn't need to become a full-time developer. Programming literacy improves test design, automation, API testing, debugging, log analysis, CI/CD work and communication with developers.

                  ISTQB and programming languagesISTQB certifications are tool- and language-agnostic: they do not teach or require proficiency in any specific programming language. ISTQB focuses strictly on software testing methodologies, principles, terminology and frameworks. The programming skills on this page complement a certification; they are not part of it.

                          Bottom line. Learn one language deeply enough to understand the fundamentals, then learn more by comparing type systems, execution models, memory models, concurrency models, tooling and ecosystems. For a QA-oriented path, TypeScript/JavaScript and Python are strong starting points; Java, C#, Go, Rust and C++ show you different engineering models. In 2026, add two habits: verify AI-generated code like code you didn't write, and let data (surveys, commit activity, local job listings), not hype, guide your language choices.
